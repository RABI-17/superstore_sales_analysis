# Superstore Sales Analysis

## Overview
Exploratory data analysis of 9,994 retail orders from a US Superstore
(2014–2017) to uncover sales trends, profit drivers, and discount impact.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab

## Key Findings
1. West region leads in total sales ($725K)
2. Furniture has only ~2.5% profit margin despite high sales volume
3. Discounts above 20% consistently result in order-level losses
4. Technology is the most profitable category at ~17% margin
5. Q4 (Nov–Dec) shows a consistent sales spike every year
